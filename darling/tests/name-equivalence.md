# File name equivalence

`name-equivalence.c` tests `darling_names_equivalent()`, the comparison guest path lookup
(`vchroot_userspace.c`) falls back to when a name is not found as given. Two names are equivalent when they are equal
ignoring ASCII case, or when both are valid UTF-8 and their canonical decompositions (Unicode Standard Annex #15) are
equal ignoring ASCII case. This makes the lookup normalization-insensitive, as APFS is. It includes
`name_equivalence.c` directly and builds on the host:

    cc -Wall -Wextra -Werror darling/tests/name-equivalence.c -o name-equivalence
    ./name-equivalence
    darling/scripts/name-equivalence-pairs.py | ./name-equivalence --pairs

The fixed cases cover:
- ASCII case;
- precomposed and decomposed letters;
- canonical ordering of marks (reordered when their classes differ, not when they share a class);
- singletons (Angstrom and Ohm signs);
- Hangul LV and LVT syllables;
- a compatibility-only decomposition (the `fi` ligature is not `fi`);
- a supplementary-plane decomposition;
- invalid UTF-8 (compared by bytes; overlong forms and encoded surrogates are invalid);
- 255-byte names;
- runs of more than 31 marks after a starter (past Unicode's Stream-Safe Text Format limit of 30), which compare by
  bytes only.

ASCII case folding applies after decomposition, so `Ü` matches `ü`. Other letters keep their case (Greek alpha is not
capital alpha).

`--pairs` reads `<expected 0/1> <hex a> <hex b>` lines from stdin. `name-equivalence-pairs.py` writes them with
Python's `unicodedata` as the reference:
- every code point against its NFD and NFC forms, alone and between ASCII letters;
- 50000 random strings of bases and marks against their NFC and NFD forms, and against each other.

Expected output: `checked 177626 pairs` (with Unicode 16.0) and `PASS name equivalence`.

The tables in `unicode_decomposition.h` are generated by `darling/scripts/gen-unicode-decomposition.py` from the
Unicode Character Database, as Python's `unicodedata` provides it. That data is under the Unicode License v3, which
is permissive. To update them, run the script with a newer Python and commit the header.
